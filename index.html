Featured Work

Acoustic Dosimeter

Two-node wireless embedded system for real-time sound exposure monitoring. The sensing node performs on-device DSP (RMS, IIR smoothing, cumulative exposure modeling) and transmits a single privacy-preserving metric over BLE to a display node — raw audio never leaves the sensor. Hit compounding real-world constraints mid-build (PCB machine failure, supply chain delays, full board rework) and demoed a fully functional system on deadline.

ML Music Genre & Instrument Classifier

Dual CNN classification pipelines for 10-class genre identification (0.77 accuracy) and 4-class instrument detection (0.71 accuracy). Led systematic experimentation from baseline logistic regression through four CNN iterations — using performance metrics and error analysis to drive improvements including SpecAugment, BatchNorm, and class-weighted loss. Full ACL-format research report included.

Motion Maven

Handheld motion-controlled game device built end-to-end on an ESP32-C3. Accelerometer-based tilt and shake detection with IIR smoothing translates physical gestures into real-time game inputs. State machine architecture with modular codebase separating motion processing, audio feedback, and persistent scoring — plus a calibration system solving per-device accelerometer variance across builds.
